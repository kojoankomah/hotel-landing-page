# Cape Breeze Boutique Hotel

## Project overview

Cape Breeze Boutique Hotel is a fictional boutique hotel located in Cape Coast, Ghana. I designed and developed this production-ready landing page to demonstrate how a hotel can present its accommodation professionally and make booking enquiries easier for potential guests.

## The problem

The hotel needed a modern online presence that would help visitors understand what it offers before making a reservation enquiry.

The website needed to:

* Present the hotel professionally
* Showcase rooms and amenities
* Promote Cape Coast as a destination
* Work properly across different screen sizes
* Allow visitors to submit booking enquiries
* Load quickly and remain accessible
* Be deployed, monitored, and maintained online

## My solution

I created a responsive hotel landing page with clear navigation, strong visual presentation, room information, amenities, destination highlights, testimonials, a gallery, and a working booking enquiry form.

The interface uses a warm coastal design inspired by the hotel’s fictional Cape Coast location. The page structure guides visitors from discovering the hotel to exploring its rooms and submitting an enquiry.

## Development process

I followed a complete production workflow:

1. Defined the fictional client, target audience, and business objectives
2. Planned the page structure and visual direction
3. Built the interface with semantic HTML
4. Created responsive layouts with CSS
5. Added mobile navigation and form behaviour with JavaScript
6. Integrated the booking form with Formspree
7. Optimized the website’s images using WebP
8. Added SEO metadata, a sitemap, and `robots.txt`
9. Connected the GitHub repository to Cloudflare
10. Deployed the website with HTTPS
11. Added Cloudflare Web Analytics
12. Configured uptime monitoring with UptimeRobot
13. Tested and improved performance and accessibility

## Production results

The deployed website achieved the following Google PageSpeed Insights scores:

| Audit          | Mobile | Desktop |
| -------------- | -----: | ------: |
| Performance    |     90 |     100 |
| Accessibility  |    100 |     100 |
| Best Practices |    100 |     100 |
| SEO            |    100 |     100 |

The mobile performance score improved from 73 to 90 after converting approximately 7.6 MB of PNG images into optimized WebP files and improving how the main image loads.

Accessibility improved from 92 to 100 after correcting colour contrast and ARIA implementation problems.

## What I learned

This project helped me understand that delivering a website involves more than writing HTML, CSS, and JavaScript. A professional website must also be deployed, tested, secured with HTTPS, connected to working services, monitored, optimized, and properly documented.

I also gained practical experience with Git-based deployments, image optimization, form integration, web analytics, uptime monitoring, accessibility testing, and production performance auditing.
